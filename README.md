# 🌠 Parallax Effects Collection

A curated collection of beautiful and interactive **Parallax Effects**.  
Each folder (e.g., `paralax 1`, `paralax 2`, etc.) contains a standalone project with `HTML`, `CSS`, and `JavaScript` files that showcase a unique visual experience.

This repository is perfect for developers, designers, and learners looking for inspiration or practical examples of parallax-based UI animation.

---

---

## 🚀 Getting Started

### ✅ Option 1: Open Directly in Browser

1. **Clone or download** the repository:
   ```bash
   git clone https://github.com/MinhPhambk/Paralax.git
   ```
   Or download the `.zip` file and extract it.

2. **Navigate to any effect folder**:
   ```bash
   cd "paralax 1"
   ```

3. **Double-click `index.html`** to open it in your browser.

---

### ✅ Option 2: Use Live Server (Recommended for Developers)

If you're using **Visual Studio Code**:

1. Install the **Live Server** extension.
2. Open any folder (e.g., `paralax 1`) in VS Code.
3. Right-click `index.html` and choose **"Open with Live Server"**.
